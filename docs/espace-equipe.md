# Publier avec l’espace équipe MK Aération

Connexion : https://mk-aeration.vercel.app/connexion

## Première connexion

Saisissez votre adresse autorisée et demandez un code. Recopiez les six chiffres reçus par e-mail. Aucun mot de passe partagé n’est utilisé. Les codes ne doivent pas être communiqués à d’autres personnes.

L’administrateur initial est **mk.aeration@hotmail.com**. Dans « Équipe & accès », il peut autoriser un collaborateur avec son nom et son adresse e-mail. Il lui communique ensuite le lien de connexion. L’ajout d’un accès ne déclenche pas d’invitation automatique par e-mail : le collaborateur demande son code lorsqu’il se connecte.

## Ajouter une réalisation ou une actualité

1. Choisir « Montrer une réalisation » ou « Partager une actualité ».
2. Renseigner un titre, une introduction et le détail de l’intervention. Pour les réalisations, préciser le type de bâtiment, le lieu et l’expertise principale.
3. Dans « Les photos », sélectionner les images sur le téléphone ou l’ordinateur. Les formats acceptés sont JPG, PNG et WebP ; sur iPhone, exporter en JPEG si le sélecteur ne convertit pas le HEIC.
4. Choisir une photo de couverture, décrire chaque photo et ajouter ses légendes. Les flèches changent l’ordre ; retirer une photo l’enlève de la fiche, sans effacer les fichiers d’origine sur le téléphone.
5. Enregistrer le brouillon. Le bandeau indique s’il reste des modifications à enregistrer.
6. Prévisualiser la fiche, puis la soumettre à validation.

Une fiche accepte jusqu’à 16 photos. Les images sont réduites et converties pour le web. Les vidéos existantes du site restent disponibles dans leurs fiches ; cet éditeur importe des photographies.

## Valider et publier

Un collaborateur prépare ses propres contenus. Un administrateur peut consulter tous les brouillons, gérer les accès et publier. Le formulaire exige un titre, une introduction, une description détaillée, une couverture et une description de chaque photo avant soumission ou publication.

Une publication n’apparaît sur le site qu’après l’action « Publier sur le site ». Les réalisations rejoignent la galerie et les actualités leur rubrique ; les plus récentes peuvent apparaître à l’accueil. Le tunnel du Mont-Blanc reste la référence principale de l’accueil et de la galerie.

## Corriger, retirer ou archiver

Modifier une publication crée un brouillon de travail. La version publique reste en place jusqu’à « Publier les modifications ». « Retirer du site » conserve le brouillon et les photos. Les publications archivées sont récupérables depuis le filtre « Archives ».

Si deux personnes modifient la même fiche, l’espace signale le conflit au lieu d’écraser les changements. Rechargez la fiche avant de poursuivre. La saisie reste à l’écran en cas d’échec d’enregistrement. Ne fermez pas la page avant le message de confirmation.

## Gérer les personnes

Le rôle « Collaborateur » permet de préparer et soumettre ses propres publications. Le rôle « Administrateur » permet de publier et de gérer les accès. Désactiver une personne bloque les prochains accès à l’espace, y compris avec une session déjà ouverte. Les contenus restent disponibles pour les administrateurs.
